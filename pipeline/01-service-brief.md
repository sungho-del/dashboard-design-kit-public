## ⚠️ 컴포넌트 공백 — 진도율/완주율 가로 막대

기획서가 **두 곳**에서 같은 UI 를 요구한다.

| 위치                 | 요구                                                       |
| -------------------- | ---------------------------------------------------------- |
| S01 강의별 완주 현황 | 완주율(%)을 **가로 막대**로, 0~100% 범위, 40% 미만 주의 색 |
| S02 표의 진도율 컬럼 | 0~100%를 **가로 막대와 숫자로 함께** (표 셀 안)            |

**확인 결과 — 구현된 35종에 이를 표현할 컴포넌트가 없다.**

- `src/components/ui/` 전수 확인: `Progress` / `ProgressBar` / `Gauge` / `Meter` 계열 **존재하지 않음**
- `Chart` 의 `BarChart` 로 대체 **불가**:
  - 세로 막대 전용 — `radius: [4,4,0,0]` 으로 위만 둥글고 바닥은 기준선에 붙는다
  - `ChartFrame` 래퍼 + `XAxis`/`YAxis`/`CartesianGrid`/`Tooltip` 을 동반한다
  - 따라서 "표 셀 안 인라인 막대"도, "강의명+수강생 수와 한 줄에 놓이는 목록형 막대"도 될 수 없다

**다만 백지는 아니다.** `docs/DESIGN.md` §26(원본에 없는 컴포넌트 — 설계 지침)에
**ProgressBar 규격이 이미 있다**: `height 4` · `radius: full` · track `surface-slate-secondary` · fill `border-slate`.
두 토큰 모두 `src/tokens/_generated.css` 에 실재한다(`--color-surface-slate-secondary`, `--color-border-slate`).
즉 **새로 발명하는 것이 아니라 기존 지침을 구현으로 승격**하는 일이다.

**단, §26 지침만으로는 기획서 요구를 못 채운다 — 두 가지가 비어 있다.**

1. **40% 미만 주의 색 임계 분기** — §26 의 fill 은 `border-slate` 단색이다
2. **표 셀 안에서 숫자와 나란히 놓이는 인라인 레이아웃** — §26 은 독립 막대만 규정한다

## 그 밖의 컴포넌트 매핑 확인

| 기획서 요구                 | 대응                                               | 판정                           |
| --------------------------- | -------------------------------------------------- | ------------------------------ |
| 상태 건수 → 누르면 필터     | `StatGrid` (value/label/count + selected/onSelect) | ✅ 정확히 일치                 |
| 기간 선택 4주/12주/6개월    | `SegmentedControl`                                 | ✅                             |
| 등록일 기간                 | `DatePicker` (range 모드 존재)                     | ✅                             |
| 선택 → 일괄 독려 메일       | `Checkbox` + `SelectionBar`                        | ✅                             |
| 행 클릭 → 우측 요약         | `SideSheet` + `InfoList`                           | ✅                             |
| 지표 4종 + 지난달 대비 증감 | `StatTile` (`delta` · `caption` prop 보유)         | ✅                             |
| 상태 배지 4종               | `Tag`                                              | ⚠️ **'수강중=정보' tone 없음** |

`Tag` 의 tone 어휘는 `default` · `success` · `warning` · `critical` · `custom` 5종이다.
기획서의 색 성격 중 **완료=성공→`success`**, **중단=주의→`warning`**, **환불=중립→`default`** 는 그대로 맞지만,
**수강중=정보**에 해당하는 tone 이 없다. `custom` tone 에 accent 계열 semantic 토큰을 주입하거나
`default` 로 낮춰야 한다 — Stage 5 판단 사항.

## 도메인 어휘

**상태 4종**

| 상태   | 뜻                  | 기획서 색 성격 | Tag tone             |
| ------ | ------------------- | -------------- | -------------------- |
| 수강중 | 진도 1~99%          | 정보           | **없음** (판단 필요) |
| 완료   | 진도 100%           | 성공           | `success`            |
| 중단   | 30일 이상 접속 없음 | 주의           | `warning`            |
| 환불   | 환불 처리됨         | 중립           | `default`            |

**임계값** — 완주율 40% 미만 = 주의 색(S01) · 중단 판정 = 30일 이상 미접속(S02)
**포맷** — 최근 학습 `YYYY-MM-DD HH:mm` · 진도율/완주율 `0~100%`
