# DESIGN_참고.md — 언제 무엇을 쓰는가

> `design-core.md`가 "무슨 값을 쓰는가", `DESIGN.md`가 "컴포넌트별 정확한 수치"라면,
> 이 문서는 **"어떤 상황에서 무엇을 고르는가"**를 규정한다.

---

## §1. 색상 선택

### 1-1. 액션 색 — 화면당 강한 강조는 1곳

| 상황                         | 토큰                                   | 예                        |
| ---------------------------- | -------------------------------------- | ------------------------- |
| 화면의 **주요 액션** 1개     | `action-primary` (near-black)          | 저장, 등록, 확인          |
| 보조 액션                    | `action-secondary` (흰 배경 + outline) | 취소, 목록으로            |
| 세 번째 이하 액션            | `ghost`                                | 더보기, 필터 초기화       |
| **파괴적** 액션              | `action-critical`                      | 삭제, 회원 탈퇴           |
| 옅은 강조가 필요한 반복 액션 | `*-tonal`                              | 테이블 행 안의 버튼       |
| 링크·인라인 강조             | `action-accent` / `text-accent` (파랑) | "자세히 보기", 하이퍼링크 |

> ⚠️ **파랑을 주 버튼에 쓰지 않는다.** 아임웹의 주 버튼은 near-black이다.
> 파랑은 "누를 수 있는 텍스트"와 accent 강조에만 쓴다.

### 1-2. 표면 — 위계는 3단이면 충분

```
bg (#edf0f4 페이지)  →  surface (흰 카드)  →  surface-sub (카드 안 옅은 영역)
```

- 카드 안에 또 카드를 넣지 않는다. 구획이 필요하면 `divide` 구분선을 쓴다.
- `surface-inverse`는 배지·툴팁 같은 작은 반전 요소에만. 큰 면적에 쓰지 않는다.

### 1-3. 상태 색

| 의미           | 토큰 계열           | 쓰는 곳                 |
| -------------- | ------------------- | ----------------------- |
| 성공·완료      | success (초록)      | 결제완료, 배송완료 태그 |
| 주의·확인 필요 | warning (머스터드)  | 재고 부족, 승인 대기    |
| 오류·위험      | critical (코럴레드) | 결제실패, 유효성 오류   |
| 정보·강조      | highlight (파랑)    | 신규, 진행중            |

- **면에는 `-secondary`(옅은 배경) + 텍스트는 같은 계열의 `text-*`** 조합이 기본이다.
  예: 태그 배경 `surface-success-secondary` + 글자 `text-success`
- `-primary`(진한 원색)는 도트·아이콘·1~2px 라인처럼 작은 면적에만 쓴다.

### 1-4. 텍스트 위계

| 토큰             | 용도                                    |
| ---------------- | --------------------------------------- |
| `text`           | 제목·본문·주요 값                       |
| `text-secondary` | 버튼 라벨·인터랙티브 요소의 기본 글자색 |
| `text-sub`       | 보조 설명·테이블 헤더                   |
| `text-minimal`   | placeholder·비활성 탭·타임스탬프        |
| `text-disabled`  | 비활성                                  |

> **아이콘은 텍스트와 별도 계열**(`icon-*`)을 쓴다. 같은 위계라도 토큰을 섞지 않는다.

## §2. 컨트롤 크기 선택

| 높이            | 언제                                             |
| --------------- | ------------------------------------------------ |
| **48** (large)  | 모달 하단 주요 버튼, 폼 제출                     |
| **40** (medium) | **기본값.** 페이지 헤더 액션, 인풋, 셀렉트, 필터 |
| **32** (small)  | 테이블 행 안, 툴바, 페이지네이션                 |
| **28** (xsmall) | 태그 옆 작은 액션, 밀집 영역                     |

- 같은 행에 놓이는 컨트롤은 높이를 통일한다.
- 크기를 줄이면 radius도 함께 줄인다(8 → 6).

## §3. 타이포 선택

| 상황                    | 클래스                                                   |
| ----------------------- | -------------------------------------------------------- |
| 페이지 제목             | `heading-2xlarge-bold` (24)                              |
| 섹션·카드 제목          | `heading-xlarge-bold`(20) 또는 `heading-medium-bold`(16) |
| **문단·설명문**         | `body-medium` (14 / 행간 20)                             |
| **버튼·인풋·메뉴 라벨** | `label-medium` (14 / 행간 24)                            |
| 캡션·보조 설명          | `body-small` (12)                                        |
| 태그·배지               | `label-small-bold`(12) 또는 `label-xsmall`(11)           |

> **body와 label의 차이는 행간이다.** 여러 줄로 흐르는 문장은 `body`,
> 한 줄로 고정된 UI 텍스트는 `label`. 14px이라고 아무거나 쓰면 세로 정렬이 어긋난다.

## §4. 간격 리듬

| 간격         | 언제                                                        |
| ------------ | ----------------------------------------------------------- |
| `gap-1` (4)  | 아이콘과 아주 가까운 라벨, 리스트 아이템 사이               |
| `gap-2` (8)  | **가장 흔한 기본값.** 아이콘↔텍스트, 버튼 사이, 인라인 요소 |
| `gap-3` (12) | 관련 있는 그룹 사이                                         |
| `gap-4` (16) | 폼 필드 사이, 블록 사이                                     |
| `gap-5` (20) | 모달 본문 블록 사이                                         |
| `gap-6` (24) | 섹션 사이, 카드 내부 패딩                                   |

- 카드 패딩은 24, 테이블 셀 패딩은 8(가장자리만 24), 페이지 좌우 gutter는 40이 기본이다.

## §5. 엘리베이션 (그림자)

```
평면(그림자 없음)  →  popover  →  layer  →  modal
```

| 그림자             | 언제                                             |
| ------------------ | ------------------------------------------------ |
| 없음               | 페이지에 붙어 있는 카드·섹션 (경계는 `border`로) |
| `shadow-popover`   | 작은 팝오버, 사이트 선택기                       |
| `shadow-layer`     | 드롭다운, 셀렉트 패널, 캘린더, 툴팁              |
| `shadow-modal`     | 중앙 모달                                        |
| `shadow-toast`     | 토스트, 선택 플로팅 바                           |
| `shadow-page-side` | SideSheet                                        |
| `shadow-gnb`       | 사이드바                                         |

> 카드에 `shadow-card`를 남발하지 않는다. 대시보드의 기본 카드는 **그림자 없이 흰 면 + 보더**다.

## §6. 인터랙션 상태

모든 인터랙티브 요소는 **5가지 상태를 반드시 정의**한다: default / hover / pressed / disabled / focus

| 상태        | 구현                                                                           |
| ----------- | ------------------------------------------------------------------------------ |
| hover       | 배경을 `*-hover`로 교체 (리스트·메뉴는 대부분 `action-secondary-hover`)        |
| pressed     | `*-pressed`. 중첩 버튼이 있는 행은 `:active:not(:has(button:active))`로 제외   |
| selected    | 강한 선택 `action-primary` + `text-inverse` / 약한 선택 `action-primary-tonal` |
| disabled    | `*-disabled` + `text-disabled` + `cursor: not-allowed`                         |
| focus       | `outline: 2px solid focus; outline-offset: -2px`                               |
| **loading** | **배경만 pressed, 텍스트·아이콘 색은 유지.** disabled와 구분할 것              |
| error       | `bg: surface-critical-secondary` + hover 시 `border-critical-hover`            |

- hover로만 나타나는 요소(드래그 핸들·삭제 버튼)는 `opacity: 0 → 1`, `transition: opacity 0.2s`.
- 상태 색 전환은 **0.1s**, 이동은 0.2s, 콘텐츠 전환은 0.3s.

## §7. 데이터 표시

- **테이블이 기본**이다. 목록형 화면에서 카드 그리드를 먼저 고려하지 않는다.
- 행 클릭이 가능하면 `cursor: pointer` + hover 배경을 반드시 준다.
- **모든 셀은 좌측 정렬이 기본이다.** 금액·수량이라고 그 컬럼만 우측 정렬하지 않는다 — 아임웹 신규 테이블 CSS에 `text-align: right`가 **한 곳도 없다**(center 7 · left 2). 레거시의 `.table-data`는 컬럼이 아니라 **표 전체**를 우측 정렬하는 통계·계산표 전용 변형이다.
- 우측 정렬이 필요하면 컬럼 하나가 아니라 표 단위로 판단할 것. `center`는 관리·체크박스처럼 폭이 좁은 컨트롤 컬럼에만.
- **행 액션(`관리`·`수정`·`상세`)은 마지막 열이다.** 첫 열은 "이 행이 무엇인가"를 답하는 자리라 식별자(이름·제목·내용)가 와야 한다. 앞에 두면 모든 행에 같은 버튼이 세로로 반복돼, 눈이 가장 자주 닿는 축을 노이즈가 차지한다. 체크박스 열이 이미 앞에 있으므로 컨트롤이 둘 연속되어 **정보 시작점이 두 칸 밀리는** 문제도 생긴다. 사용자는 _무엇을_ 고칠지 정한 뒤 버튼을 누르므로 순서도 뒤집힌다.
  - 예외는 **열이 아주 많아 우측 끝이 먼 표**다(19열짜리 주문 목록 등). 4~5열짜리 표는 우측 끝이 코앞이라 이 예외가 성립하지 않는다.
  - 원본 화면이 앞에 두고 있어도 이 규칙을 따른다. 그 경우 **왜 원본과 다른지 뼈대 상단 주석에 남긴다**(예: `src/pages/babycube/HolidayListPage.tsx`).
- `table-fixed`가 기본이므로 **`<colgroup>`으로 컬럼 폭을 반드시 지정한다.** 지정하지 않으면 컬럼이 균등 분배되어 짧은 컬럼이 늘어진다. 한 컬럼만 `auto`로 두는 것도 피할 것 — 화면이 넓어질 때 그 컬럼이 남는 공간을 전부 흡수해 다른 컬럼과 멀어진다. 비율(%) 배분이 안전하다.
- 상태 값은 텍스트만 쓰지 말고 **Tag(dot + 라벨)** 로 표현한다.
- 빈 상태는 반드시 처리한다 — 아이콘 72 + 안내 문구. 크기는 `DESIGN.md` §16.
- 일괄 선택이 가능한 테이블은 **Selection Floating Bar**(§25)를 함께 제공한다.

## §8. 아이콘

**라이브러리: `lucide-react`** (Clay가 인라인 SVG + stroke 방식을 쓰기 때문에 선택)

```tsx
import { ShoppingCart } from "lucide-react";
<ShoppingCart size={20} strokeWidth={1.2} className="text-icon" aria-hidden />;
```

- **`strokeWidth`는 1.2**가 기본이다 (Clay의 `--border-icon` 토큰과 동일). lucide 기본값 2를 그대로 쓰지 않는다.
- 크기는 **16 / 20 / 24**만 쓴다. GNB·인라인 20, 큰 버튼 24, 작은 버튼·태그 16.
- 색은 `icon-*` 계열을 `className`으로 준다(`currentColor` 상속). 버튼 안에서는 버튼 variant의 텍스트 색을 따른다.
- 의미 없는 장식 아이콘은 `aria-hidden`, 단독으로 의미를 갖는 아이콘 버튼은 `aria-label` 필수.
- 시안·목업 단계에서는 플레이스홀더 박스(토큰 그레이 + 정확한 프레임 크기)로 처리한다.
- 의미를 아이콘만으로 전달하지 않는다 — 툴팁이나 라벨을 병행한다.

## §9. 접근성

- 텍스트 대비 **4.5:1** 이상. `text-minimal`(slate-400)은 **placeholder·비활성 전용**이며 본문에 쓰지 않는다.
- 포커스 링을 제거하지 않는다(`outline: none` 금지). 필요하면 `:focus-visible`로 조건을 좁힌다.
- 색만으로 상태를 전달하지 않는다 — 아이콘/텍스트 병행.
- 클릭 타겟은 최소 28px, 권장 32px 이상.
- 모달·SideSheet는 열릴 때 포커스를 가두고, 닫으면 트리거로 되돌린다.

## §10. Don'ts

| ❌ 하지 말 것                                     | ✅ 대신                            |
| ------------------------------------------------- | ---------------------------------- |
| `bg-blue-500`, `var(--color-slate-900)` 직접 사용 | `bg-action-accent`, `text-text`    |
| 파랑을 주요 버튼 색으로 사용                      | `action-primary` (near-black)      |
| `#1a6dff` 등 레거시 색 참조                       | 폐기됨. Clay 토큰만                |
| `text-sm`, `text-[15px]`                          | 프리셋 24종 (`body-medium` 등)     |
| `p-[15px]`, `gap-[10px]`                          | 4px 그리드 유틸 (`p-4`, `gap-2.5`) |
| `border: 1px solid` 로 상태 전환                  | `outline` + 음수 offset            |
| `outline: none`                                   | `:focus-visible` 로 범위 조정      |
| 카드 안에 카드 중첩                               | `divide` 구분선                    |
| 그림자를 위계 없이 남발                           | §5 엘리베이션 4단                  |
| 임의의 transition 값                              | 0.1 / 0.2 / 0.3s 3종               |
| 컴포넌트에 `dark:` 분기                           | 라이트 전용. 토큰 구조로 대응      |
| 빈 상태 미처리                                    | §16 규격의 Empty State             |
