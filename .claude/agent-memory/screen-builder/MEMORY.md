# Memory Index

- [no invented values](feedback_no-invented-values.md) — 원본에 없는 값을 만들지 말 것 — 특히 요약 카드의 증감(±)과 상태 어휘. 빈칸은 "지어내도 된다"는 뜻이 아니다
- [original diff pass](feedback_original-diff-pass.md) — 원본 대조 작업에서는 "우리에게 있는데 원본에 없는 것"을 빼는 것이 핵심이다 — 빈칸을 그럴듯한 것으로 채우지 말 것
- [page test queries](feedback_page-test-queries.md) — 페이지 테스트를 쓸 때 접근가능 이름을 지어내지 말고 실물에서 확인할 것 — 조정자가 지적한 반복 실패 원인
- [report failures](feedback_report-failures.md) — 리허설·검증 작업에서는 잘 된 것보다 막힌 지점을 그대로 보고할 것 — 실패 목록이 산출물이다
- [table alignment](feedback_table-alignment.md) — 표 셀 정렬은 좌측이 기본이고 자릿수를 비교하는 수치만 우측이다 — 원본이 center 여도 좌측으로 통일한다
- [verify accessible names](feedback_verify-accessible-names.md) — 테스트 쿼리를 쓰기 전에 그 접근가능 이름을 실제로 렌더하는 코드가 있는지 확인할 것 — 지어내면 5건씩 한꺼번에 깨진다
- [verify per file tests](feedback_verify-per-file-tests.md) — 화면을 하나 끝낼 때마다 그 화면의 테스트 파일만 vitest 로 돌려 통과시키고 넘어간다 — 그리고 접근가능 이름을 지어내지 않는다
- [stage5 rehearsal](project_stage5-rehearsal.md) — Stage 5 리허설 4회 경과(차트온 3 + 클래스온 1) — 템플릿에 실물 예가 없는 부품, 문서·실물 불일치, 스키마 빈칸 목록
